玩法

你控制自己创建的角色；DM 与其他队友由 AI Agent 扮演。探索时直接输入行动或对白 （AI 模式），或按菜单选择（剧本模式）；战斗按回合从底部按钮选择动作。 指令：/状态 /背包 /短休 /长休 /保存 /退出。

规则速查（D&D 5e）

· d20 + 调整值 vs DC；优势与劣势同时存在时互相抵消。
· 命中 AC 造成伤害，天然 20 暴击（伤害骰翻倍），天然 1 必失。
· 0 HP 进入死亡豁免：3 次成功稳定、3 次失败身亡，伤害会自动记一次失败。
· 专注法术受创需体质豁免；黑暗中无黑暗视觉攻击劣势（记得带火把）。
· 里程碑升级：关键剧情后全队升级（模组内定义）。

接入 DeepSeek / GLM / Kimi / MiniMax

到「设置 → API 配置」选择供应商并填入密钥即可；也支持环境变量方式 （CTRCG_LLM_API_KEY 或供应商官方变量如 DEEPSEEK_API_KEY）。 所有供应商统一走 OpenAI 兼容 /chat/completions 协议。

自己写模组

每个模组是一个自包含 JSON 文件：modules/<id>/module.json， 放入后即可被加载。完整规范见项目内 docs/MODULE_SPEC.md， 内置模组 modules/starfall/module.json 就是现成模板； 也可在「新的冒险」页用 AI 一键生成。

设置

骰子、命中、升级与终局各有音效；设置保存在本浏览器。
