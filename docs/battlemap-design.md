# 战术地图与 DM 独立 Agent 设计（ctrcg 2.0 · 《赛博朋克 RED》口径）

版本 1.1 · 适用 `ctrcg` ≥ 2.0 · 上游文档：`aipc-design.md`（ST 提示词栈）、
`companion-npc-agents.md`（同伴/NPC Agent 架构）、`../MODULE_SPEC.md`（模组规范）

## 0. 一句话总览

> **DM 升级为带空间权威的独立 Agent（同一条 SillyTavern 组装线）；
> 战术网格让"谁站在哪"从叙事默认变为引擎结算——剧情期由 DM 调度棋子，
> 战斗期由引擎按《赛博朋克 RED》逐格结算（1 格 = 2 米）。位置实时推送，
> LLM 依旧只决策、不结算。**

## 1. 缘起与目标

1.6.0 完成了"全员 Agent 化"：玩家 AI 代打（AIPC）、同伴独立 Agent、
NPC 子智能体。当时明确遗留两件事：

- **DM 未上 ST 组装线**（手拼模板、无世界书、无深度注入——aipc-design §P1）；
- **世界没有空间概念**：场景是单链文本节点，"近战/远程"按戏剧脑内二分法
  近似（剧场模式），位置、走位、射程全部不存在。

1.7.0 补齐这两块：

| 角色 | 1.6.0 | 1.7.0 起 |
|------|-------|-------|
| 玩家 PC | 人操 / AI 代打 | 不变；战斗获得点图移动 |
| 同伴（非玩家 PC） | 独立 Agent（ST 线） | 不变；战斗获得战况图与 move/dash 工具 |
| **DM** | 工具循环 LLM（手拼模板） | **ST 组装线 + 世界书加餐 + 深度注入 + 空间权威（map_update）** |
| NPC | DM 控制子智能体 | 不变；上下文增加地图态势（只感知不改动） |
| 战斗 | 剧场模式（近战/远程二分） | **双轨**：有地图 → 战术网格；无地图 → 剧场模式逐字节保留 |

2.0.0 把整套规则换成《赛博朋克 RED》轻松模式口径：网格单位改为
**1 格 = 2 米**，远程难度值按**射程带查表**，掩体与护甲磨损取代了旧规则层的
黑暗视觉与范围法术形状。

## 2. 数据模型

### 2.1 运行时（`GameState.map`）

```python
state.map = {
  "scene_id": "the_pier",
  "image": "assets/maps/pier.jpg",        # None = 纯网格无图
  "label": "旧码头 · 三号仓库外",
  "grid": [12, 8],                         # 战斗网格 [宽, 高]，1 格 = 2 米
  "image_grid": [20, 12],                  # 源图自带格数（合成图裁剪用）
  "crop": [6, 2, 12, 8],                   # 分幅裁剪（None = 整图）
  "obstacles": [[0, 0], ...],              # 阻挡格：不可进入、挡视线
  "tokens": {
    "pc:薇":       {"name": "薇",  "kind": "pc",      "cell": [2, 4], "icon": None},
    "npc:broker_wei": {"name": "Wei", "kind": "npc",  "cell": [11, 7], "icon": "assets/tokens/broker_wei.png"},
    "mon:码头义体帮": {"name": "码头义体帮", "kind": "monster", "cell": [10, 4], "icon": ...},  # 仅战斗期
    "prop:crate":  {"name": "货箱", "kind": "prop",   "cell": [5, 3], "icon": ...},
  },
}
```

- `None` = 本局无地图（旧模组/旧档）→ 全部地图与网格分支短路，**旧行为
  逐字节保留**（双模式铁律，见 §6）。
- 存档随 `map` 键持久化（旧档无此键 → 读档 `None`）。
- 探索期棋子的唯一事实源是 `state.map.tokens`；战斗期是
  `Encounter.positions`（`rules/combat.py`），每回合由 session 写回 tokens。

### 2.2 模组 schema（`MODULE_SPEC.md` §4.2/§5）

顶层 `tokens`（图标库）、顶层 `dm`（DM 卡扩展）、场景 `map`、遭遇 `spawns`。
校验器同步扩展：资产路径安全（禁 `..`/绝对路径/扩展名白名单）、格坐标界内、
crop 不越源图、spawns 引用必须参战。

### 2.3 战斗层（`rules/combat.py`）

```python
METERS_PER_CELL = 2          # 1 格 = 2 米

class BattleGrid:            # 纯几何：Chebyshev 距离 / Bresenham 视线 / 8向BFS / 方形范围
    dist / dist_m / has_los / path / cells_within

@dataclass Encounter:
    grid: BattleGrid | None  # None → 剧场模式
    positions: dict          # 名字 → (x, y)
    speed_left: dict         # 名字 → 本回合剩余移动力（米）
    cover: dict              # 格 → [材质, 耐久]
```

## 3. DM 独立 Agent（ST 组装线 + 空间权威）

1. **同一条组装线**：`make_dm_agent` 改走 `st.assemble_system`——main =
   `DM_SYSTEM_TEMPLATE`（template_vars 预格式化），模组顶层 `dm` 块可提供
   `persona/voice/system_prompt（{{original}} 覆盖）/depth_prompt/book`。
   模组可用 `dm` 块注入整体演出基调与战场提示（内置模组
   《赛博朋克 RED：轻松模式》注入的是雨夜霓虹与"子弹比嘴快"的基调）。
2. **世界书加餐**（aipc-design §P1 落地）：`session._dm_wi` 每轮把
   `engine_worldinfo(state)`（场景/旗标/检定/NPC 条目）与模组 `dm.book` 合并，
   按本轮文本（玩家输入 + 桌上插话）扫描，命中内容以【世界书】段注入。
3. **真·深度注入**：`harness.loop.run` 新增 `post_build(messages)->messages`
   钩子；DM 的 `depth_prompt` 与扫描结果的 `at_depth` 条目经
   `st.inject_at_depth` 真插入消息列表中部（消除 P0 的"块内排序"降级形态）。
   事件日志按注入前记录（注入条目源自已记录的世界书扫描，不变量保持）。
4. **空间权威工具 `map_update`**：探索/社交期 DM 用
   `place/move/remove/label` 四种操作调度棋子（越界/障碍/占用格被引擎拒绝，
   拒绝不阻塞）；任一成功即广播地图快照。战斗期工具明确拒绝（棋子归引擎）。
5. **DM 上下文**：每轮 user 消息新增【地图】段（地图名、网格、障碍数、
   各棋子坐标），DM 因此能在叙述里引用位置并主动调度。

## 4. 战术网格规则（1 格 = 2 米）

- **距离**：Chebyshev（斜向 1 格 = 2 米）；两人距离 = 格数 × 2 米。
- **射程**：远程攻击按**射程带查难度值**（0-6 / 7-12 / 13-25 / 26-50 /
  51-100 / 101-200 / 201-400 / 401-800 米，每类武器一列）——
  手枪与霰弹枪超过 200 米直接打不到，突击步枪能打到 800 米。
  RED 没有"优势/劣势"，远近距离的差别全部体现在查表得到的 DV 上。
- **移动**：`combat_action move(x,y)` / 玩家菜单"移动"——8 向 BFS 寻路，
  队友可穿不可停、敌人格不可穿、终点不可占用；每格扣 2 米移动力；
  **倒地时不能移动**，必须先起身（`stand` 消耗一半移动力）；
  `dash` 追加一次移动力；移动力 = 机动 × 2 米，每轮重置。
- **借机攻击**：移动中任何一步离开敌人的贴身格（≤ 2 米）→ 该敌人消耗
  **反应**执行一次借机攻击（引擎只结算一次攻击，不触发武器的多次攻击 LA）。
- **视线**：Bresenham 直线，途经障碍格 → 远程攻击被拒（"视线被地形阻挡"）；
  目标所在格有耐久大于 0 的**掩体**时同样视为被掩护、没有射击线。
- **掩体**：`Encounter.set_cover` 按材质写入耐久（厚钢 50、薄钢 25、厚石 40、
  薄石 20、厚混凝土 25、厚木 20、薄防弹玻璃 15、薄木 5），可对 2m × 2m 区域
  发起攻击，耐久归零即被摧毁。
- **范围**：轻松模式**没有法术范围效果**，因此网格只提供 `cells_within`
  （以某格为中心的方形范围）供掩体、爆炸叙事与 AI 走位参考，不做 AOE 形状裁切。
- **贴身纠缠**：位置变化后从坐标重建 `engagement`（相邻 ≤ 2 米的敌人）——
  白刃战/斗殴的对抗检定、擒抱/锁喉/投掷与远程的贴身判定都据此获得空间语义。

## 5. 谁在何时移动棋子（实时性）

| 时刻 | 行动者 | 通路 |
|------|--------|------|
| 换场 | 引擎 | `enter_scene` 按场景 `map` 声明换图布子 |
| 探索/社交剧情 | **DM Agent** | `map_update` 工具 |
| 玩家探索移动 | 玩家点图 | Web `/api/command` → `map:move x,y` → 转 DM 裁定 |
| 遭遇开始 | 引擎 | 队伍沿用探索位置，敌人按 `spawns`/对侧散开 |
| 战斗每回合 | 引擎 | 玩家点图/`move` 工具/敌人与脚本 AI `npc_choose_action`（逼近/后撤） |
| 战斗结束 | 引擎 | 敌人棋子撤下、队伍最终位置写回 |

广播通路：`GameSession.broadcast_map()` → `ui.map_update(state.map_brief())`
→ Web 为 SSE `map` 事件（**全量快照、latest-wins**；事件日志重放使断线
重连零成本重建地图），终端为静默记录（`/地图` 指令查看文字态势）。
前端棋子按 id 增量更新坐标（CSS transition 平滑滑动），底图/网格变化才重建。

**点图落子**：玩家回合选"移动"→ 引擎经 `WebUI.ask_map_move` 阻塞 →
前端进入点图模式（提示条 + 点击任意格）→ 点击翻译为 `x,y` 文本应答 →
`_walk_path` 逐格结算（含借机）。终端回退 `free_input` 输坐标。

## 6. 双模式铁律（兼容性）

- `state.map` 为 `None` ⇔ `Encounter.grid is None` ⇔ 剧场模式：
  所有射程/移动分支短路，战斗路径与网格模式上线前逐字节一致。
- 场景有无 `map` 可逐场景混合：同一模组可以有的场景打网格、有的打剧场
  （无图场景战斗退回剧场，位置检查全部跳过）。
- 敌人/脚本 AI 的走位只在网格模式激活；LLM 参战者的 `move/dash` 工具在
  剧场模式明确报错（不会静默吞掉）。
- 玩家菜单防死锁：网格模式下连续无效行动（闸门拒绝不耗动作）6 次后
  自动收束动作阶段。

## 7. LLM 的位置感知

- **同伴/AIPC**：战斗回合任务注入 ASCII 战况图
  （`你/P/m/#` 逐格渲染 + 自身坐标 + 剩余移动力 + move/dash 用法提示）。
- **敌人/脚本队友**：纯启发式（近战 `approach` 逼近最近可打格、远程被贴身
  后撤拉开；重伤且胆小的杂兵会 `flee`），确定性、零 LLM。
- **NPC 子智能体**：对话上下文附一行【地图】态势（只感知，无改动工具）。
- **DM**：【地图】段（§3.5）。

## 8. 明确不做（本轮出界）

掩体带来的减伤加值（掩体只提供射击线判定与自身耐久）、困难地形、侧翼、
体型占多格、光照层级（手电与赛博光学只作 DM 叙事依据）、拖拽他人棋子、
无图模组补图（机制通用，按 MODULE_SPEC 补 JSON 即可）、
战斗中 DM 参与回合决策（敌人行动保持引擎启发式——延迟与确定性取舍）、
以及轻松模式未收录的子系统（自动武器/压制射击、网络空间、载具战斗、
武术、药物）。
